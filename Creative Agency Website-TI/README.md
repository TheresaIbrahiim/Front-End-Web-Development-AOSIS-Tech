# Creative Agency Website

A modern Creative Agency website built as a front-end development project using HTML5 and CSS3. The website includes sections for featured works, services, pricing, team members, and recent news.

## 🌐 Live Demo

[View Live Website](https://theresaibrahiim.github.io/Front-End-Web-Development-AOSIS-Tech/Creative%20Agency%20Website-TI/index.html)

## ✨ Features

- Sticky navigation bar
- Hero section with call-to-action buttons
- Featured works / portfolio section
- Services section
- Why Choose Us section
- Statistics section
- Pricing table
- Team section
- Recent news section
- Hover effects and CSS transitions
- Font Awesome icons

## 🛠️ Technologies

- HTML5
- CSS3
- Font Awesome
- Git & GitHub
- GitHub Pages

## 🎯 Purpose

This project was created as part of my Front-End Web Development training at AOSIS Tech to practice building and styling a complete multi-section website using HTML and CSS.
