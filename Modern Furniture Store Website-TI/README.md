# Modern Furniture Store Website

A modern and responsive furniture store website designed to showcase furniture collections, featured products, promotions, and shopping services. The project focuses on creating an attractive user interface using HTML5 and CSS3.

## 🌐 Live Demo

[View Live Website](https://theresaibrahiim.github.io/Front-End-Web-Development-AOSIS-Tech/Modern%20Furniture%20Store%20Website-TI/index.html)

## ✨ Features

- Furniture navigation menu with dropdown
- Hero banner section
- Special furniture categories
- Promotional discount banners
- Customer testimonial section
- Free delivery and customer service section
- Featured products section
- 3D product flip card effect
- Product ratings
- Social media icons
- Hover effects and CSS transitions
- Service icons using CSS sprite positioning

## 🛠️ Technologies

- HTML5
- CSS3
- Font Awesome
- Git & GitHub
- GitHub Pages
