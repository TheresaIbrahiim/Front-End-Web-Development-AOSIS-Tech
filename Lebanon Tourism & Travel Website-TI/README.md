# Lebanon Tourism & Travel Website

A responsive tourism and travel website designed to showcase the beauty and destinations of Lebanon. The website provides information about popular Lebanese destinations, travel sections, translation tools, Lebanon news, and social media links.

## 🌐 Live Demo

[View Live Website](#https://theresaibrahiim.github.io/Front-End-Web-Development-AOSIS-Tech/Lebanon%20Tourism%20&%20Travel%20Website-TI/index.html#)

## ✨ Features

- Responsive navigation bar
- Lebanon-themed design
- Trips dropdown menu
- Search bar
- Login modal
- Responsive image carousel
- Social media sidebar
- Welcome section
- Popular destinations section
- Accordion for destination information
- Arabic to English translation section
- Arabic to French translation section
- Arabic to German translation section
- Copy-to-clipboard functionality
- Fixed background/parallax-style sections
- Popular destination cards
- Hover effects and animations
- Lebanon news and podcast section
- Social media subscription and follow section
- Responsive footer

## 📍 Featured Destinations

The website showcases several destinations in Lebanon, including:

- Beirut

- Byblos
- Baalbek
- Jeita Grotto
- Harissa
- Raouche
- Dream Park
- Tripoli
- Saint Charbel
- Al Kobayat
